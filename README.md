# Pupu

Pupu is a virtual pet that lives in the FoloToy AI Passport: a black-faced little lamb spirit that hatched from an ink egg. You can feed it, pat its head, and play the "Catch the Stars" mini-game with it, and it slowly grows up; when it connects to the phone, it learns how long you were away and syncs its status to the phone.
