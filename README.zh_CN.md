# 噗噗（Pupu）

噗噗是一只住在 FoloToy AI Passport 里的电子宠物：一只从墨水蛋里孵出来的黑脸小羊精灵。你可以喂它、摸摸它、陪它玩「接星星」小游戏，它会慢慢长大；连上手机时，它会知道你离开了多久，并把近况同步到手机上。
